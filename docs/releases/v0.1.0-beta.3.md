# Sükûn v0.1.0-beta.3

**TR — Herkese açık test sürümü; henüz kararlı değildir.**

- Normal kullanıcı ekranından geliştirici araçları kaldırıldı: medya testi, test ayrıntıları ve yerel günlük açma düğmesi yalnızca Debug derlemelerinde gösterilir.
- Windows ile başlatma, vakit yenileme ve uygulama güncellemesi tercihleri korunur. Medya kontrolü, otomasyon, yerel ayarlar ve sınırlı yerel günlükler değişmedi.
- Windows 10 (2004+) / Windows 11 x64. `Sukun-win-x64.exe` .NET içerir; ayrıca kurulum gerekmez. ZIP aynı EXE ile lisans/gizlilik bildirimlerini içerir. SHA256SUMS imza yerine geçmez, dosya bütünlüğünü karşılaştırmak içindir.

**EXE henüz dijital olarak imzalanmadı.** Windows güvenlik politikaları çalıştırmayı engelleyebilir; güvenlik korumalarını kapatmayın. Bu paketin gerçek oynatıcılarla duraklatma/devam ettirme ve tüm Windows sürümlerinde çalışma testi tamamlanmadı. Geri bildirimler için GitHub Issues kullanılabilir.

**EN — Public beta, not a stable release.** Developer media trial/details and the local-log shortcut now appear only in Debug builds. Startup, timetable refresh and update preferences remain available. Media automation, settings and bounded local diagnostics are unchanged. Windows 10 (2004+) / Windows 11 x64; .NET is included.

**Unsigned:** Windows may block this EXE. Keep security protections enabled. Actual media control and startup of this exact distributed package remain unverified; automated checks are not a substitute for supported-device testing.
