# Sükûn v0.1.0-beta.4

**TR — Herkese açık beta; henüz kararlı sürüm değildir.**

- Yeni betalar artık algılanır; kararlı sürüm kullananlar beta kanalına geçirilmez. Eski sürüm/taslak ve geçerli EXE dosyası bulunmayan yayınlar sunulmaz.
- Gelişmiş ayarlarda otomatik sürüm kontrolünü açarsanız günde bir denetlenir. Yeni sürüm için bir kez tepsi bildirimi gelir; mola sırasında bekler. Bildirime veya Güncelle’ye tıklayınca indirme sayfası için onay sorulur. Windows bildirimleri sessize almış olabilir; uygulamadaki düğme de yeni sürümü gösterir.
- Otomatik indirme, kurulum veya yeniden başlatma yapılmaz; yayın sırasında kontrol kullanıcının elindedir.
- Pencere tepside gizliyken gereksiz arayüz güncellemeleri azaltıldı. Medya duraklatma/devam ettirme sahiplik kuralları korundu. Geliştirici araçları Release sürümünde gizli kalır.
- Windows 10 (2004+) / Windows 11 x64. .NET pakete dahildir. EXE, ZIP ve SHA256SUMS eklidir.

**EN — Public beta, not a stable release.** Beta installations now discover later betas; stable users stay on stable releases. Daily checks are opt-in. One-time tray notices wait during an active media break. Clicking a notice or Update asks before opening GitHub; no automatic download, installation or restart. Hidden-window UI work is reduced; media ownership safeguards remain unchanged.

**Validation:** Release build and **100/100 automated checks** passed, including fake HTTP responses, prerelease ordering, safe download URLs, notification persistence/deferral, offline failures and idle media polling. The website resolver's 10 checks passed. Windows notification delivery, actual player control and resource/battery use of the exact final package are not yet established on independent devices.

**Unsigned / İmzasız:** Windows security policies may block this EXE. Keep protections enabled. Venue operators should trial the intended player and location before relying on it. This beta is not certified for unattended business/event use.
