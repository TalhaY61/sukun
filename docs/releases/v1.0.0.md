## Türkçe

Sükûn’un ilk sürümü: namaz vakitlerinde medyaya küçük bir ara.

- Windows 10/11 x64 için taşınabilir uygulama; .NET kurmanız gerekmez.
- Diyanet vakitleri, kayıtlı tarihlerde çevrimdışı çalışma ve açık konum seçimi.
- Türkçe/İngilizce, açık/koyu tema, tray kullanımı ve seçilebilir medya kaynağı.
- Yalnızca uygulamanın duraklattığı medya devam ettirilir; güncelleme kontrolü isteğe bağlıdır.

**İndir:** `Sukun-win-x64.exe`. ZIP seçerseniz önce içeriğini çıkarın. `SHA256SUMS.txt` dosya bütünlüğünü kontrol etmek içindir; dijital imza değildir.

**Bilinen sınırlar:** EXE henüz dijital olarak imzalanmamıştır; Windows uyarabilir veya engelleyebilir. Son paketin gerçek medya ve ayrı Windows 10 cihaz testleri tamamlanmamıştır. Özellikle etkinliklerde kullanmadan önce kendi oynatıcınızla deneyin. Bu yayın önceki sürümün işlevlerini korur; sürüm numarasının değişmesi ek cihaz doğrulaması anlamına gelmez.

[Kullanım ve indirme](https://talhay61.github.io/sukun/) · [Hata bildir](https://github.com/TalhaY61/sukun/issues/new/choose)

## English

The first Sükûn release: a little pause at prayer time.

- Portable Windows 10/11 x64 app; no separate .NET installation.
- Diyanet prayer times, offline use for saved dates and explicit location selection.
- English/Turkish, light/dark themes, tray operation and selectable media sources.
- Resumes only media the app paused; update checks are optional.

**Download:** `Sukun-win-x64.exe`. Extract the ZIP first if you choose that option. `SHA256SUMS.txt` verifies file integrity; it is not a digital signature.

**Known limits:** The EXE is unsigned; Windows may warn or block it. Final-package real-media tests and testing on a separate Windows 10 device are not complete. Try your intended player before venue use. This release retains the previous implementation; a new version number does not represent additional device validation.
