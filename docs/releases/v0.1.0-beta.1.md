# Sükûn v0.1.0-beta.1

İlk herkese açık test sürümü / First public test release.

- Namaz vakitlerinde medyayı duraklatır; yalnızca kendi duraklattığı oturumu devam ettirir.
- Türkiye için Diyanet vakitleri, kayıtlı tarihlerde çevrimdışı kullanım.
- Küçük WPF pencere, system tray, açık/koyu/sistem teması ve anlık TR/EN geçişi.
- Hesap, reklam, telemetri veya otomatik günlük gönderimi yok.

**Download:** `Sukun-win-x64.exe` is self-contained; no .NET installation needed. ZIP includes the same EXE and license/privacy notices. Windows 10 (2004+) / Windows 11 x64. Verify files with `SHA256SUMS.txt`.

**Beta limitations:** unsigned build; not a stable release. Windows/player compatibility still needs wider testing. Browser media must expose Windows media controls. A pause uses the configured duration; the app does not listen for the end of the adhan. Saved prayer dates require a download when their coverage ends. App updates are checked manually or opt-in; they are not installed automatically.

Report bugs: https://github.com/TalhaY61/sukun/issues/new/choose
Verification details: [BETA-VERIFICATION.md](../BETA-VERIFICATION.md).

**Known verification limit:** the final published EXE was blocked by Windows Application Control on the development machine. No security protection was bypassed. Automated tests passed (83/83), and a real YouTube Music pause/resume succeeded on the preceding executable; this does not claim that the final EXE launched successfully on that machine. See the [current verification report](https://github.com/TalhaY61/sukun/blob/main/docs/BETA-VERIFICATION.md).
