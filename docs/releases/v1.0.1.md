## Türkçe

- Güncelle onayı artık GitHub Releases yerine Sükûn indirme sitesini açar.
- Gelişmiş ayarlarda çalışan uygulamanın sürümü görünür.
- Taşınabilir güncelleme adımları açıklandı: yeni EXE’yi indirin, eski uygulamada **Çıkış**’ı seçin ve yeni dosyayı açın. X yalnızca gizler. Ayarlar korunur.
- Aynı sürümün farklı derleme bilgisiyle yeniden güncelleme sayılmadığı doğrulandı. Yeni dosyayı indirmek arka plandaki eski uygulamayı değiştirmez; tek uygulama kuralı korunur.

Windows 10/11 x64, .NET kurulumu gerekmez. EXE imzasızdır; Windows uyarabilir veya engelleyebilir. Son paketin gerçek medya testleri tamamlanmamıştır.

[Windows için indir](https://talhay61.github.io/sukun/) · [Hata bildir](https://github.com/TalhaY61/sukun/issues/new/choose)

## English

- Update confirmations now open the Sükûn download website instead of GitHub Releases.
- Advanced settings shows the version that is actually running.
- Clear portable update steps: download the new EXE, choose **Quit** in the old app, then open the new file. X only hides the window. Settings are preserved.
- Verified that build metadata alone does not cause the same version to be offered again. Downloading an EXE does not replace an older running instance; the single-instance rule is preserved.

Windows 10/11 x64, no separate .NET installation. The EXE is unsigned; Windows may warn or block it. Real-media tests of the final package are not complete.
