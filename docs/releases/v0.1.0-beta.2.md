# Sükûn v0.1.0-beta.2

**TR — Test sürümü; henüz kararlı değildir.** Namaz vakitlerinde seçtiğiniz medyayı duraklatan ve belirlediğiniz süre sonunda devam ettiren küçük bir Windows tepsi uygulaması.

- Windows 10 (2004+) / Windows 11 x64; ayrıca .NET kurmanız gerekmez.
- Türkçe/İngilizce arayüz, açık/koyu tema, yerel ayarlar ve indirilen tarihler için çevrimdışı vakitler.
- Güncel pause + û ikonu; yeni ekran görüntüleri ve temiz başlangıç yapılan kaynak deposu.
- `Sukun-win-x64.exe` dosyasını indirin; ZIP aynı EXE ile lisans/gizlilik bildirimlerini içerir. SHA256SUMS dosyasındaki değerlerle bütünlüğünü kontrol edebilirsiniz.

**Önemli:** EXE henüz dijital olarak imzalanmadı. Smart App Control veya diğer Windows güvenlik politikaları çalıştırmayı engelleyebilir. Güvenlik korumalarını kapatmayın. Bu sürüm, böyle sistemlerde sorunsuz çalıştığı iddiasıyla yayımlanmamaktadır.

**EN — Public beta, not a stable release.** Sükûn pauses your selected media at prayer time and resumes it after your chosen interval. Windows 10 (2004+) / Windows 11 x64; .NET is included. Turkish/English, light/dark themes, local settings and cached prayer dates are supported.

**Unsigned:** Windows security policies may block this EXE. Keep protections enabled. The exact package has not been validated across supported Windows/player combinations. Historical player tests on earlier builds are not a successful test of this EXE. See the [verification report](https://github.com/TalhaY61/sukun/blob/main/docs/BETA-VERIFICATION.md).
