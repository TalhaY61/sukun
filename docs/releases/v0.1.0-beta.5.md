# Sükûn v0.1.0-beta.5

**TR — Test sürümü.** İlk açılışta boş vakit kartları yerine belirgin **Konum seç** adımı gösterilir. İl seçilince Diyanet merkez vakit bölgesi yüklenir; sonrasında bölge değiştirilebilir. Hazır konum olmadan otomasyon açılamaz. Yeni kurulumda Ankara veya başka bir il varsayılan değildir; kayıtlı konum ve dil tercihleri korunur. Otomatik konum, IP sorgusu veya konum takibi eklenmedi.

**EN — Public beta.** Clean installs show a clear **Choose location** action instead of empty prayer cards. Selecting a province loads its official central prayer-time area. Automation stays unavailable until valid location/times are ready. No preset Ankara location, IP lookup or geolocation tracking. Existing location/language preferences are preserved.

Windows 10 (2004+) / Windows 11 x64; .NET included. Beta/stable update channels and opt-in daily notifications from beta.4 are retained. No automatic installation or restart.

**Validation:** Debug/Release builds and 101 automated application checks; clean-install defaults and existing media/update regression coverage. Final-package real-player control, native notification delivery and independent-device performance remain unverified.

**Unsigned / İmzasız:** Windows may block this EXE. Keep security protections enabled. This is a beta, not a validated unattended venue solution.
